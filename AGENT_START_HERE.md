    TreeStream Agent Instructions

Before making any changes:

1. Read the following files completely:
   - SPEC.md
   - SCENARIOS.feature
   - ACCEPTANCE_CRITERIA.md

2. Treat SPEC.md as the authoritative source of behavior.

3. Do not modify:
   - SPEC.md
   - SCENARIOS.feature
   - ACCEPTANCE_CRITERIA.md

4. Implementation code must exist only in:
   IMPLEMENTATION/

5. Follow this loop:

   read specification
   generate or modify implementation
   run scenario tests
   produce REVIEW.md
   produce TEST_REPORT.md
   iterate until all scenarios pass

6. If a specification ambiguity is found, stop implementation and report it in REVIEW.md.

Do not add features not defined in SPEC.md.
